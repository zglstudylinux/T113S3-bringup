# T113 开发板 原理图功能引脚分析

> 依据：`T113.pdf`（Schematic_2，共 7 页：1 CORE / 2 NET / 3 POWER / 4 CONNECT / 5 AUDIO / 6 FLASH / 7 DISPLAY，嘉立创 EDA，V1.0）。所有网络名、位号、器件值均取自图上可见文字；图上不可见的信息标注 `UNKNOWN`。

## 1、电源架构分析：输入电源路径

| 电源轨 | 来源器件 | 输出 | 去向 | 备注 |
|---|---|---|---|---|
| VIN5V | 调试 Type-C（USB10，KH-TYPE-C-16P）VBUS | 5V 输入 | 经 D23（LMBR240FT1G 肖特基）→ 5V | CC1/CC2 经 R141/R142 5.1kΩ 下拉（Sink）；U33/U34 ESD5451N 保护 USB0_DP/USB0_DM |
| 5V | 供电 Type-C（USB9，KH-TYPE-C-16P）VBUS | 5V | 全板 5V 母线 | CC1/CC2 经 R113/R114 5.1kΩ 下拉；U35/U36 ESD5451N 保护 USB1_DP/USB1_DM；两条输入路径并联供电 |
| 5V 指示 | R115 10kΩ + LED3（NCD0603B1） | — | 5V → R115 → LED3 → GND | 电源指示灯，5V 在即常亮，非 GPIO 控制 |
| 3V3 | U27 SY8088AAC（降压，L20 2.2uH） | 0.6×(1+R108 680kΩ/R107 150kΩ)≈3.3V | VCC-IO、VCC-PD、VCC-PE、VCC-PG、Flash/TF/RTL8723DS/屏/触摸等外设 | EN 接 5V（常开）；C107/C108 10uF；T113-S3 的 VCC-PC/PF 在芯片内部连接到 VCC-IO |
| 1V5 | U28 SY8088AAC（降压，L21 2.2uH） | 0.6×(1+R109 300kΩ/R111 200kΩ)=1.5V | VCC-DRAM | EN 接 5V；图注：使用 T113S3 时 VCC-DRAM 应该使用 1.5V |
| 0V9 | U29 SY8088AAC（降压，L23 2.2uH） | 0.6×(1+R110 150kΩ/R112 300kΩ)=0.9V | VDD-CORE、VDD-SYS | EN 接 5V |
| 1V8 | U54 SY8088AAC（降压，L22 2.2uH） | 0.6×(1+R153 300kΩ/R152 150kΩ)=1.8V | AVCC、HPVCC、VCC-PLL、VDD18-DRAM、VCC-LVDS、VCC-RTC | EN 接 5V |
| AVCC | 1V8 经 L8（GZ1608D601TF 磁珠） | 1.8V 模拟电源 | T113 AVCC（Pin 89） | C9 10uF/C12 100nF、C13/C14 去耦；R79 0Ω 单点桥接 GND↔AGND；C82/C83 470nF 为 VRA1/VRA2 去耦 |
| 屏背光高压 | U52 MT9201（boost：5V→L18 10uH→SW，D22 LMBR240FT1G 整流） | LEDA/LEDK 回路 | FPC1 Pin20 LEDA / Pin22 LEDK | EN 由 LCD_PWM（PD22）控制，R120 10kΩ 下拉；R121 10Ω 为 LED 电流采样（FB） |

`输入路径`：调试 Type-C（VIN5V）→ D23 LMBR240FT1G → 5V ←（并联）供电 Type-C（5V）→ U27/U28/U29/U54 四路 SY8088AAC → 3V3 / 1V5 / 0V9 / 1V8 → T113 各电源域；1V8 再经 L8 磁珠 → AVCC；5V → U52 MT9201 boost → 屏背光。

## 4、驱动逻辑分析

- **WiFi/BT 模块（RTL8723DS，U11，页 2）**：SDIO 四线接 PG0/PG1/PG2/PG3/PG4/PG5（WL_SDIO_D0/D1/D2/D3、CMD、CLK），CLK 串 R90 33Ω；RN2/RN3（10kΩ×8）将 D0–D3、CMD、CLK、WL_DIS#（Pin12）、WL_DEV_WAKE_HOST（Pin13）全部上拉至 3V3；BT HCI 经 UART1（PG6 TX→模块 UART_IN，PG7 RX←UART_OUT，PG8 RTS→UART_CTS，PG9 CTS←UART_RTS）；BT_DIS#（Pin34）经 R52 10kΩ 上拉 3V3，SUSCLK_IN（Pin24）经 R91 10kΩ 上拉 3V3（图注：RTL8723DS/RTL8189 需要，RTL8723BS 不需要）；VBAT_IN/VDDIO 接 3V3，C63 100nF/C64 10uF/C65 10uF 去耦；ANT（Pin2）经 L10（AN2051-245）接板载天线（该走线上绘有 X 未连接标记）；PCM、VBAT_EN、BT_HOST_WAKE_DEV、BT_DEV_WAKE_HOST、MAIN_XTAL_IN 均未连接。驱动方式：SDIO 复用 + UART1 复用；WL_DIS#/WAKE 为 GPIO。
- **BLE MESH 模块（MX-02，U5，页 2）**：UART0 直连——PE2（UART0_TX）→模块 Pin8 P03/RX，PE3（UART0_RX）←模块 Pin9 P02/TX；3V3 供电（Pin10），Pin2/11 接地；P06（Pin16）接 GND，图注：0=正常模式可收发，1=低功耗仅能发送（板上固定为正常模式）；P08/P09/P10/P04/P05/RST/SEL0/ANT 均未连接。
- **SPI NAND Flash（W25N01GVZEIG，U1，页 6）**：SPI0 四线——PC3 CS#（R122 10kΩ 上拉）、PC5 MISO←DO、PC4 MOSI→DI、PC2 CLK；PC7 HOLD#（R93 10kΩ 上拉）、PC6 WP#（R145 10kΩ 上拉）；VCC 3V3 + C1 100nF；SW1 按键将 SPI0_MOSI 对地短接（配合启动/烧录），U21 ESD5451N 保护。驱动方式：SPI 复用，片选 GPIO/复用。
- **TF 卡（TF-02A，CARD1，页 6）**：SDIO（PF0–PF6）四线 + CD 检测；R32–R37（10K）对 SDIO_D0–D3、CMD、CD 上拉至 3V3；卡座 VDD 3V3，C2 100nF 去耦；Pin10–13/GND 接地。驱动方式：SDC0 复用。
- **MIPI 屏幕（FPC1 24P，页 7）**：DSI 差分——PD0/PD1（MIPI_0_P/N）、PD2/PD3（MIPI_1_P/N）、PD4/PD5（LCD_CLK_P/N）；MIPI_LCD_RST（PD20）低有效复位（图注：拉低复位）；MIPI_LCD_TE（PD21）为屏输出的 TE 状态脚；Pin5/6 接 3V3，Pin7/10/13/16/19 接 GND，Pin21 NC，Pin23/24 屏蔽地。触摸经同一 FPC：TP_SDA/TP_SCL（PE1/PE0，I2C）、TP_INT（PE5）、TP_RST（PE4），RN1 10kΩ×4 上拉至 3V3。驱动方式：DSI 复用 + I2C 复用 + GPIO。
- **屏背光（MT9201，U52，页 7）**：5V 输入 boost，L18 10uH 储能，D22（LMBR240FT1G）整流后输出 LEDA（FPC Pin20），LED 电流经 LEDK（FPC Pin22）回到 FB，R121 10Ω 电流采样；EN（Pin4）由 LCD_PWM（PD22）驱动，R120 10kΩ 下拉——PD22 低时背光关断，PWM/高电平点亮调光；C144/C141/C119 去耦。
- **模拟麦克风（GMI4015P-2C-42db，MIC2，页 5）**：差分模拟麦——正极经 C85 100nF → MIC_IN_3P（Pin87），负极经 C86 100nF → MIC_IN_3N（Pin88）；AVCC 经 R148 75Ω、C143 10uF 滤波后由 R147 1kΩ 给正极偏置，R146 1kΩ 为负极偏置至 AGND；C87 100pF 差分滤波。驱动方式：codec 模拟输入。
- **扬声器功放（LM4871，U53，页 5）**：T113 HPOUTR（Pin98）→ C142 470nF → R136 20kΩ → IN-（Pin4），IN+（Pin3）经 R149 20kΩ 接 VO+（增益网络）；SHUTDOWN（Pin1）由 PA_SHDN（PB2，Pin86）控制，R138 100kΩ 下拉至 GND——默认使能，PB2 拉高关断（SHUTDOWN 高有效）；VDD（Pin6）5V，C139 10uF；BYPASS（Pin2）接 C138 1uF；VO+/VO-（Pin5/8）经 U49/U50 ESD5451N 接扬声器座 CN2（HC-1.25-2PWT）；左声道 HPOUTL（Pin99）直接接 GND（单声道应用）；HPOUT_FB（Pin100）接 C91 100nF 至 AGND。
- **USB（页 4）**：USB0 调试 Type-C（USB10）：DP1/DM1 与 DP2/DM2 并联接 USB0_DP/USB0_DM，CC1/CC2 经 R141/R142 5.1kΩ 下拉（Sink），VBUS=VIN5V，U33/U34 ESD；USB1 供电 Type-C（USB9）：USB1_DP/USB1_DM，CC 经 R113/R114 5.1kΩ 下拉，VBUS=5V，U35/U36 ESD。驱动方式：USB 控制器复用，无需 GPIO。
- **调试串口（U24 ZX-MX1.25-3PWT，页 4）**：Pin1=UART3_RX（PB7）、Pin2=UART3_TX（PB6）、Pin3=GND，U37/U38 ESD5451N 对地保护。驱动方式：UART 复用。
- **用户 LED（LED4/网络 LED1，页 4）**：VCC-IO → R124 10kΩ → LED4 → LED1（PD11）——低电平点亮，高电平/高阻熄灭。
- **用户按键（SW5，网络 BTN1，页 4）**：VCC-IO → R126 10kΩ → BTN1（PD10），C124 100nF 至 GND 消抖，SW5 按下将 BTN1 拉低，U42 ESD5451N 保护——低有效按键。
- **复位电路（页 1）**：VCC-IO → R13 10kΩ → RESET（Pin27），C41 100nF 至 GND，SW2 手动复位（按下拉低），U41 ESD5451N——低有效复位，上电由 RC 建立高电平。
- **时钟电路（页 1）**：X1 24MHz（XL2EL89COI-111YLC-24M）接 DXIN/DXOUT，C122/C123 12pF；X2 32.768kHz 接 X32KIN/X32KOUT，C120/C121 12pF，R14 10MΩ 跨接增益电阻。无需软件配置。
- **板间地（页 1/5）**：R79 0Ω 连接 GND 与 AGND（模拟单点接地）；DZQ（Pin47）经 R123 240Ω 接 GND（DRAM 校准电阻）。
